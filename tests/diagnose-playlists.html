Which playlist list is actually being used?

This tells you, from your real Spotify tab, whether the extension is reading Spotify's own Add to playlist sheet (the correct list) or silently falling back to scraping the Your Library sidebar (the wrong one).

Run it

  1. Open https://open.spotify.com and start playing something.
  2. Open DevTools (F12) → Console.
  3. Open tests/diagnose-playlists.js, copy the whole thing, paste it into the console and press Enter.
  4. Copy the printed block back here.

Reload the extension first if you have just changed the code, then refresh the Spotify tab — the diagnostic reads what the running extension actually does.

What it prints

GATE 1  curation button ...... found / NOT FOUND + why
GATE 2  liked state .......... true / false / null
GATE 3  click opens sheet .... yes / no (+ how long it took)
GATE 4  sheet rows ........... N menuitemcheckbox rows, and whether each
                                resolves to a spotify: uri
GATE 5  source that won ...... "curation" (correct)  or  "library" (wrong)
SHEET    rows currently rendered in OUR OWN bottom sheet

The line that matters is GATE 5. If it says library, the correct sheet either never opened or never mounted its rows — GATE 3 and GATE 4 say which.
